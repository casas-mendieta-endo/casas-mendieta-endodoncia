# Sitio profesional de endodoncia

Página estática, adaptable y lista para GitHub Pages. No requiere instalar dependencias.

## Contenido incorporado

El sitio ya contiene los datos profesionales, formación, experiencia, matrículas, teléfono, correo, redes sociales, dirección y fotografías del Dr. Jorge Alejandro Casas Mendieta.

Antes de publicarlo, se recomienda una última lectura para confirmar la redacción y comprobar que el teléfono recibe mensajes por WhatsApp.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí todos los archivos de esta carpeta a la raíz del repositorio.
3. Abrí **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná `main`, carpeta `/ (root)` y guardá.

GitHub mostrará la dirección pública en esa misma pantalla.
